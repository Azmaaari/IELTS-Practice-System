  - 9个主要路由
  - 懒加载组件
  - 路由元信息
  - 全局导航守卫

**路由列表**:
```
/                        → HomeView
/search                  → SearchView
/practice/:id            → SinglePracticeView
/practice/full-test/confirm → FullTestConfirmView
/practice/full-test      → FullTestView
/history                 → HistoryView
/history/:sessionId      → HistoryDetailView
/stats                   → StatsView
/settings                → SettingsView
```

### 6. ✅ Pinia状态管理

创建了4个Store：

- **examStore** - 题库状态
  - manifest加载
  - chunk缓存
  - 文章加载

- **practiceStore** - 练习会话
  - 会话管理
  - 答案收集
  - 计时器
  - 本地持久化

- **historyStore** - 练习历史
  - IndexedDB操作
  - 统计计算

- **userStore** - 用户设置
  - 主题、字体、高亮颜色
  - 本地持久化
