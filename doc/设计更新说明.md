## 🔑 关键设计要点

### 1. HTML元素和CSS类名必须一致

| 题型 | 工作流HTML | Vue组件渲染 |
|------|-----------|-----------|
| 填空题 | `<input class="blank">` | `<input class="blank">` |
| 拖拽卡片 | `<div class="card" draggable="true">` | `<div class="card" draggable="true">` |
| 拖拽目标 | `<span class="dropzone" data-target="q14">` | `<span class="dropzone" data-target="q14">` |

**✅ 完全一致，无差异**

---

### 2. 答案格式规范

根据工作流要求：

```javascript
// 工作流中的答案格式
const answers = {
  q14: "b",              // ✅ 小写单个字符
  q22: "disease",        // ✅ 小写单词
  "q20-21": ["A", "D"]   // ✅ 多选题用数组
}
```

**Vue中的答案收集**:
```typescript
const userAnswers = ref<Record<string, string | string[]>>({
  q14: "b",
  q22: "disease",
  "q20-21": ["A", "D"]
})
```

**✅ 格式完全一致**

---

### 3. 拖拽实现细节

**关键属性对应**:

| JSON字段 | HTML属性 | 说明 |
|---------|---------|------|
| `content.canReuse` | `data-clone="true"` | 控制选项是否可重复使用 |
| `content.options` | `.card` 元素 | 生成可拖拽卡片 |
| `answer` | `data-value` | 正确答案值 |

**拖拽事件**:
- `dragstart`: 设置传输数据
- `dragover`: 允许放置（preventDefault）
- `drop`: 处理放置

**✅ 使用HTML5原生拖拽API，与工作流一致**

---

### 4. 多选题特殊处理

**题号范围显示**:
- HTML工作流：`<strong>20-21</strong>`
- Vue组件：`{{ questionRange }}` → "20–21"

**选择数量限制**:
```vue
<input 
  type="checkbox"
  :disabled="isDisabled(option.label)"
>
```

**答案格式**:
- 必须是数组：`["A", "D"]`
- 即使只选一个也用数组：`["A"]`

**✅ 逻辑与工作流完全一致**
