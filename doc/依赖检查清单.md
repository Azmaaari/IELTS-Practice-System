## 🔧 常见问题

### Q: 为什么显示很多 EBADENGINE 警告？

A: 这些警告是因为我的终端使用的是 Node.js 16.20.2。这些警告不影响安装，但**运行时必须使用 Node.js 22+**。

### Q: 如何确保使用正确的Node版本？

A: 在项目根目录创建 `.nvmrc` 文件:
```bash
echo "22" > .nvmrc
```

然后在项目目录下执行：
```bash
nvm use
```

会自动切换到 Node.js 22。

### Q: 如何重新安装所有依赖？

A: 
```bash
rm -rf node_modules package-lock.json
npm install
```
